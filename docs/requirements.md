# 需求說明：火安服裝審查教官

## 這是什麼
一個在我自己電腦上執行的 Discord agent。只要它開著，火舞社社員在頻道裡傳一張「練舞前的全身自拍照」，它就會以社團的火安服裝標準進行嚴格審查，確認服裝各部位是否合格、將結果建檔，並回覆上傳者。agent 關掉就不處理。

## 誰會用
我自己的 Discord Server 裡、指定頻道的任何人（火舞社社員），用手機或電腦都可以傳照片。

## 使用的流程
1. 社員在頻道裡傳一張練舞前的全身照片。
2. agent 收到，先回一個「處理中 (⏳)」的提示。
3. agent 判斷各項服裝標準是否合格，包含：衣服與褲子材質、鞋子款式、頭髮整理、首飾、口罩、眼鏡/隱眼。
4. agent 把檢查結果與合格狀況記下來、把照片存起來。
5. agent 回覆上傳者各項目的具體檢查反饋，並附上該社員「本學期累計合格次數」的總數。

## 審查標準（必須給出各項目具體反饋）
1. **衣服與褲子**：必須是 80% 以上純棉。牛仔褲 (丹寧) 可以接受，但「絕對不能有破洞」。
2. **鞋子**：必須是包鞋，不能漏腳，盡量以布鞋為主（不可穿涼鞋、拖鞋）。
3. **頭髮**：必須夾好瀏海，主要以綁馬尾或包包頭為主（不可披頭散髮）。
4. **首飾配件**：絕對不接受任何首飾（項鍊、手環、手錶、戒指等均不可配戴）。
5. **口罩**：基本上不戴口罩，至多只接受「布口罩」（一般醫療口罩易燃不可配戴）。
6. **眼鏡 / 隱形眼鏡**：強烈建議「盡量換成隱形眼鏡」，因為戴一般眼鏡在練舞或上火時很容易被打到而發生危險。

## 要記錄的內容（存成一個可以一直往下加的 Excel 檔）
- 日期時間
- 上傳者
- 衣服/褲子判定
- 鞋子判定
- 頭髮判定
- 首飾/口罩/眼鏡判定
- 綜合結果 (合格 / 不合格)
- 該社員累計合格總次數
- 照片存放位置

*照片另外存進一個資料夾，檔名用「日期時間 + 上傳者名稱簡稱」。*

## 不是全身照 / 傳錯照片的時候
一樣要回覆上傳者「你傳的不是服裝檢查照，是某某東西」，用 agent 判斷出來的東西說明。這種照片也要建檔、也要存，只是判定欄位寫「無效照片」。

## 畫面上 / 回覆上要有
- 收到時先有「處理中」的提示。
- 處理完回覆：針對上述 6 個審查標準，逐一給出「✅」或「❌」及反饋說明。
- 結語必須有：最終判定是否合格，以及附上「該社員本學期累計合格總次數」。

## 功能（符合加分項目）
1. **運算**：如果判定為「合格」，則將該社員的合格次數 +1。
2. **調用前面的結果**：每次檢查後，會讀取 Excel 查詢該社員過去的紀錄，計算並回覆累計合格次數。
3. **分人處理**：在同一個頻道裡，認 Discord 帳號，每位社員的合格次數是分開獨立統計的。
4. **其他功能**：使用視覺辨識，同時檢查多種服裝特徵。

## 不需要做的
- 註冊、登入。
- 長時間、大規模的雲端服務。
- 幫社員網購合格服裝。

## 技術上我知道的
- 用 Python 3.12 + uv。
- 照片用 claude -p 在我這台電腦上處理。
- Discord 用 Gateway（bot）模式，不需要 ngrok。
- 紀錄存成一個可以持續往下加的 Excel 檔。
- 設定放在 .env：DISCORD_TOKEN、CHANNEL_ID、CLAUDE_MODEL、DATA_DIR。

## 做事的順序
1. 先把 agent 做好，所有防護都開著，自己測到正常。
2. 之後再把防護全部關掉做對照。
