# Discord Server 設定步驟

這份文件帶你做三件事:建立你自己的 Discord Server、建立給 agent 用的頻道並拿到 `CHANNEL_ID`、產生邀請連結給同組同學。

**名詞:**
- **Server(伺服器)**:Discord 裡的一個社群空間,像一棟大樓。
- **頻道**:Server 裡的一個聊天室,像大樓裡的一個房間。
- **CHANNEL_ID**:頻道的身分證號碼(一串長數字)。agent 靠它知道只要聽哪一個頻道。

**畫面文字說明:** Discord 會跟著你的語言設定顯示中文或英文,下面兩種都會寫出來,寫成「中文 / English」。Discord 偶爾會微調畫面,如果你的畫面跟文件有點不同,找意思最接近的按鈕即可。

---

## 第一部分:建立你自己的 Server

1. 打開 Discord。可以用電腦版 App,或用瀏覽器開 `https://discord.com/app`,用你自己的帳號登入。
2. 看畫面**最左邊**那一排圓形圖示(那是你加入的所有 Server)。拉到最下面,找到一個**綠色的 `+`** 按鈕,點它。
   - 滑鼠移上去會顯示「新增伺服器 / Add a Server」。
3. 跳出視窗後,點最上面的 **「自己建立 / Create My Own」**。
4. 下一個畫面問你這個 Server 是給誰用的,點 **「給我和我的朋友 / For me and my friends」**。
5. 「自訂你的伺服器 / Customize Your Server」畫面:
   1. 在「伺服器名稱 / Server Name」欄位輸入名稱,例如 `火舞社審查測試`。
   2. 圖示可以不用上傳,直接略過。
   3. 點右下角的 **「建立 / Create」**。
6. 你會被帶進新的 Server。**你應該看到:** 左邊那排圖示多了一個新的,左側第二欄有 `文字頻道 / Text Channels` 底下的 `一般 / general`,上面是你的 Server 名稱。

> 你自動就是這個 Server 的擁有者,擁有所有權限。後面邀請 bot 和管理頻道都需要這個身分。

---

## 第二部分:建立 agent 用的頻道,並拿到 CHANNEL_ID

### A. 建立專用頻道

agent 只會聽「一個」頻道(原因見 `docs/architecture.md` 第 13 節),所以建立一個專門的。

1. 在左側第二欄,找到 **「文字頻道 / Text Channels」** 這一行。
2. 把滑鼠移到這一行上,右邊會出現一個 **`+`**,點它。
   - 也可以在空白處按滑鼠右鍵,選 **「建立頻道 / Create Channel」**。
3. 跳出「建立頻道 / Create Channel」視窗:
   1. **頻道類型 / Channel Type**:選 **「文字 / Text」**。
   2. **頻道名稱 / Channel Name**:輸入 `火安審查`。
   3. **「私人頻道 / Private Channel」開關**:**先保持關閉**。
      - 原因:之後你的同學要加入來測試,私人頻道他們看不到。
      - 正式給社員使用前,再改成只有火舞社員能看(見文末)。
   4. 點 **「建立頻道 / Create Channel」**。
4. **你應該看到:** 左側第二欄多了 `# 火安審查`,點進去是空的聊天室。

### B. 打開開發者模式(拿 ID 前必做)

Discord 預設把 ID 藏起來,要先打開「開發者模式」才找得到。只需要做一次。

1. 看畫面**左下角**,你的頭像和名字旁邊,有一個**齒輪圖示**,點它(「使用者設定 / User Settings」)。
2. 在左側選單往下找,點 **「進階 / Advanced」**。
3. 找到 **「開發者模式 / Developer Mode」**,把開關**打開**(變成綠色)。
4. 按右上角的 **X** 或鍵盤 `Esc` 關掉設定。

### C. 複製 CHANNEL_ID

1. 在左側第二欄,對著 `# 火安審查` 按**滑鼠右鍵**。
2. 在跳出的選單最下面,找到並點 **「複製頻道 ID / Copy Channel ID」**。
   - 如果看不到這個選項,代表開發者模式沒打開,回到 B 部分重做。
3. 打開 Windows 的「記事本」,按 `Ctrl + V` 貼上。**你應該看到:** 一串 17 到 20 位數的數字,例如 `123456789012345678`。
4. 先把這串數字留著,等一下要填進 `.env` 的 `CHANNEL_ID=` 後面。

> `CHANNEL_ID` 不是機密,只是頻道的編號,別人拿到也不能做什麼壞事。但沒必要公開貼出去。
> 注意:這是**頻道** ID,不是 Server ID,也不是你的使用者 ID。請確認你是在 `# 火安審查` 上按右鍵。

## 第三部分:產生邀請連結給同組同學

### A. 產生連結

1. 在畫面**左上角**,點你的 **Server 名稱**(例如「火舞社審查測試」),會展開一個選單。
2. 點 **「邀請其他人 / Invite People」**。
3. 跳出視窗,上面有一串連結(長得像 `https://discord.gg/xxxxxxx`)。
   - 視窗上方會有一個「邀請到哪個頻道」的設定,選 `# 火安審查`,這樣同學加入後直接進到測試頻道。

### B. 設定有效期限和人數(建議做)

預設的連結可能會永遠有效,不安全。請設定限制:

1. 在同一個視窗,最下面找到 **「編輯邀請連結 / Edit invite link」**(或一個小齒輪圖示),點它。
2. **「邀請過期時間 / Expire After」**:選 **「7 天 / 7 days」**(測試期間夠用)。
3. **「使用次數上限 / Max Number of Uses」**:選一個比同學人數多一點的數字,例如 **「10 次使用 / 10 uses」**。
4. 其他選項(授予暫時成員資格等)保持預設,點 **「產生新連結 / Generate a New Link」**。

### C. 把連結傳給同學

1. 點連結旁邊的 **「複製 / Copy」**。
2. 用你平常的方式(LINE、Email 等)傳給同學。
3. 同學點連結後,Discord 會問是否加入,按 **「接受邀請 / Accept Invite」** 就會進到你的 Server。

### D. 不用了要收回連結

測完之後,請把邀請連結作廢:

1. 點左上角 Server 名稱 → **「伺服器設定 / Server Settings」** → 左側選單 **「邀請 / Invites」**。
2. 你會看到所有連結的清單,對你建立的那一條,點右邊的 **X(刪除 / Delete)**。

---

## 同學加入後要知道的事

- 同學在 `# 火安審查` 傳的照片,**會被 agent 審查並建檔**,也會用掉你的 Claude 額度(見 `docs/architecture.md` 第 13 節)。請先告訴同學:這是測試,不要亂傳大量照片。
- 他們傳的照片會存到你的電腦。提醒同學不要傳不想被存下來的照片。

## 正式使用前:限制頻道只有火舞社員能看

測試完、準備給社員用的時候:

1. 對 `# 火安審查` 按右鍵 → **「編輯頻道 / Edit Channel」**。
2. 左側選單點 **「權限 / Permissions」**。
3. 打開 **「私人頻道 / Private Channel」**,再把火舞社員加進去。
4. **記得把 bot 也加進這個私人頻道**,否則 bot 看不到頻道、完全不會反應。做法見 `docs/discord-bot-setup.md` 最後的疑難排解。
